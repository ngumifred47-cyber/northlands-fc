# Northlands FC

Static website for Northlands FC. GitHub Pages deploys the site automatically when changes are pushed to the `main` branch.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub for this website.
2. Add these website files to the repository and push them to the `main` branch.
3. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
4. Open the **Actions** tab and wait for the **Deploy Northlands FC site** workflow to finish. GitHub will show the public website URL in the Pages deployment details.

The deployment workflow is in `.github/workflows/pages.yml`.
